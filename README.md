# HARFLER public support site

Static support and privacy pages for HARFLER: Sayı İstilası.

- Website: https://lowgame.github.io/harfler-site/
- Support: https://lowgame.github.io/harfler-site/support/
- Privacy: https://lowgame.github.io/harfler-site/privacy/

Publish `main` from `/` with GitHub Pages. No build step, external assets or analytics scripts are used.

This repository contains only the public website. The game's source, signing material and private configuration are not included.
